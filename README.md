# Anthem Workshop

A Git and GitHub practice project built by three users (Satish, Rajesh, Ramesh) on an AWS EC2 instance.

## What this project shows
- Cloning and pushing a repository
- Commits by multiple users
- Branching and merging
- A simple Flask app (`app.py`) that displays the national anthem

## Files
- `anthem.txt`: anthem text
- `app.py`: Flask app
- `templates/index.html`: web page
